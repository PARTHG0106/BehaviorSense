Six levers implemented, all measured rather than assumed. One thing I found by reading the code changed the plan materially.

## Balanced sampling was already on

`train_adl.py` already uses effective-number class weighting (Cui et al.). So naive logit adjustment on top would have **corrected the imbalance twice** — and produced a worse number that looked like a failed experiment.

But effective-number weighting *saturates by design*. At 65,000 windows for `other_idle` against 69 for `bending_reaching` it removes roughly 145× of a ~942× ratio, leaving ~6.5× residual imbalance. That residue is exactly the gap between the training objective and mean-class accuracy. So the lever is real — it just has to be a **swept τ**, not a derived one, because how much the sampler left is a property of the data.

`train_adl.py` now refuses `--sampler balanced --tau-train >0` with the fix in the message, in the style of the existing focal-alpha guard. A warning inside a 12-hour log isn't read until the result is already wrong.

## What's in

| lever | mechanism | cost |
|---|---|---|
| logit adjustment | `τ·log(prior)` at decision time, swept, τ=0 as control | free |
| stream subset selection | all 15 subsets × 2 combination rules | free |
| test-time flip | mirror each window, average logits | 1 extra pass |
| Viterbi segment accuracy | the metric Agent 3 actually consumes | free |
| logit-adjusted training loss | `--sampler natural --tau-train τ` (Menon et al. 2021) | a training run |

**The segment metric is the one I'd care about most.** Every accuracy number we've reported is per-window. Agent 3 never sees a window — it consumes smoothed segments and derives every daily feature from their durations. `viterbi()` and `smooth()` have existed since Agent 2 was written and had **never been evaluated on real data**. The deployment metric was simply unmeasured.

On the TTA flip: negating x without remapping left/right joints produces a body whose left wrist sits on its right side — a pose no human adopts and the model never trained on.
