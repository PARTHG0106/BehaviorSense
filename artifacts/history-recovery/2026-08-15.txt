Yes — several remain, and the newest one is now implemented. Here's the honest ranked list, grounded in the measured numbers.

## Just built: second-person context — the free object signal

`interacting_with_person` is the second-worst class (F1 0.042) *because* pose alone can't express "someone else is here." But every shard already carries **two person slots**, and slot 1 is non-zero exactly when the tracker held a second person. The extraction pipeline recorded the missing signal in every window, and `OBJECT_PRIORS["person"]` (+1.5 log-odds on class 18) was written for it — and has never once received it.

`second_person_present()` derives the flag from slot-1 occupancy: ≥3 visible joints in ≥5 frames, so single-frame tracker flicker doesn't fire it. It feeds `fuse_objects()` — the same code path serving uses, not a parallel evaluation copy. The notebook measures it with and without logit adjustment, and prints class-18 recall/precision specifically so you can see *why* it moved rather than just a delta in an average.

Test P15 pins the three failure modes: reading slot 0 instead of slot 1 (would fire on every window — asserted against), counting flicker as a person, and the fusion not actually raising class 18 (verified ×4.3 on flagged windows, relative odds bit-exact elsewhere). 145 fast tests pass.

## The rest, ranked by expected value

**1. RT-DETR object fusion — still the biggest, still not built.** The measured per-class floor is exactly the object-dependent classes: `taking_medication` 0.043, `watching_tv` 0.089, `using_phone` 0.091. The second-person lever just covered class 18 from existing data; these three need the actual detector. `rtdetr-l.onnx` is staged and verified by preflight — what's missing is an ONNX inference wrapper implementing the `ObjectDetector` protocol and object→window association. It's the only remaining lever that adds *information*; everything else redistributes what the skeletons carry. Substantial work; say the word.

**2. The `walking` label-map audit — cheap, possibly large.** 563 windows, 1.7% of val, F1 0.192 — for the most pose-separable activity in the taxonomy, in a corpus of people moving around their homes. The Charades keyword rule (`\bwalk|\brunning\b|\bjogging\b`) is almost certainly missing verbs like "Running through a doorway" variants and routing locomotion into `other_idle`. **3. Logit-adjusted training** (`--sampler natural --tau-train 1.0`) — the trained version of the post-hoc lever that already gave +0.050. Costs a notebook-03 run (~3 h). Worth it only after 1 and 2, because those change what the model sees, and retraining before them would be retrained on the same starved labels.

**4. NTU-60 pretraining** — the preflight has been warning `MISSING stgcnpp_ntu60_joint.pth` since notebook 00.
