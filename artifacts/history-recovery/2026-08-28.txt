## No, nothing about the individual is stored

I traced every write on the serving path:

- **The video** goes to `tempfile.mkdtemp(prefix="bs-upload-")` and is `shutil.rmtree`'d in two separate `finally` blocks ([_generate.py:3767](notebooks/_generate.py:3767) and [:3786](notebooks/_generate.py:3786)), so it goes even if decode raises or the stream dies. The decode child uses its own `TemporaryDirectory` ([video.py:409](src/behaviorsense/video.py:409)).
- **No body embeddings are ever computed.** `ENROL_GALLERY = False` sets `OSNET = None`, so OSNet isn't loaded at all. That's *why* every track reads `unidentified` — there's no gallery to match against and nothing is added to one. Identity can't be stored because it's never computed.
- **Agent 3 keeps no history.** `BehaviourAnalyzer` is constructed fresh per request inside `primed_reference()`, primed from the simulator, and garbage-collected when the request ends. Its `_history` is 21 simulated days plus this clip's one day.
- The only `open`-like call anywhere on the serving path is the HTTPS POST in `openrouter.py`. No features, segments, reports, or frames are written to disk.

**What does leave your machine, and you should state this in an ethics section:** the video bytes go to the Kaggle tunnel for Agents 1–2, and Agent 4 sends the **feature table** — 27 numbers, durations, z-scores, and a date — to OpenRouter. ## The bug: `is_reliable` was always true

```python
"is_reliable": bool(getattr(today, "is_reliable", False))   # a bound METHOD is always truthy
```

`is_reliable` is a method, not a property. So a 29-second clip with `observed_hours = 0.01` was published as a **reliable day**. Proof:

```
f.is_reliable()                          -> False
bool(getattr(f, "is_reliable", False))   -> True
```

`stages.js` keys its own warning off that field — *"Observed span is 0.010 h, far below the 8 h a day needs to be called reliable"*. Look at your Agent 3 card: that sentence is missing. The bug deleted the one line telling a caregiver not to act on these numbers. Fixed in both copies ([staging.py](src/behaviorsense/service/staging.py) and the notebook's), and W6 now asserts the **value**, not the key — the same key-comparison blind spot that suite was written after.

From **29 seconds** of someone cooking. And all six claims passed all five checks — correctly.
