## What I built this session

**Fixed the two things left mid-flight.** Agent 2's failures came down to one design bug: abstention was gating on `posterior[viterbi_label]`, so it discarded exactly the windows smoothing had just repaired (visible as a spurious `other_idle` segment mid-walk). ## Two real defects found by measurement

The one worth flagging: **`normalise()` was erasing falls.** Per-frame root-centring — the textbook skeleton normalisation — subtracts the body's trajectory, which mathematically removes whole-body descent. The fall smoke test scored **AUROC 0.466, below chance**, on data whose only signal was a 1.5-unit hip drop; post-normalisation the two classes were byte-identical. This would have crippled the fall head on OmniFall and looked like a data problem. Fixed by centring on the window's first frame, pinned by test S4b which asserts descent survives *and* translation invariance holds — the existing test only checked the second.

The other: resume was changing the LR curve. Cosine schedule is a function of total epochs, so resuming with different `--epochs` silently puts the optimiser on a different curve. Now refused outright, and S7 simulates a timeout properly via `--stop-after` (6-epoch run == 3+resume, max EMA delta 2e-8).
